# python-class

## Python Login & Registration System

A simple Login and Registration application developed using Python.

### Technologies Used

* Python
* Tkinter (GUI)
* SQLite3 (Database)

### Features

* User Registration
* User Login
* Password Verification
* Database Management

### Requirements

* Python 3.x

### How to Run

1. Download or clone the repository.
2. Make sure Python is installed.
3. Configure the database path if necessary.
4. Run ui.py.

### Database

This project uses SQLite to store user information.

## ⚠ Important Note

Before running the program, please check the database path in the following line of code:

data = Database('d:/lesson/project/data.db')

You must change the database path according to your own computer’s directory. Otherwise, the program may not find the database file.
